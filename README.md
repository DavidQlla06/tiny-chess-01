A compact chess engine in Python that plays the make.fun tiny-chess-01 gauntlet: alpha-beta search with a transposition table, killer moves, a capture quiescence search and a fixed node budget, packed into 4,096 bytes.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
